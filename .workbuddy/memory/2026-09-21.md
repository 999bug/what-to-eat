### 1. 电脑端滚轮无法滚动页面
- 根因：`html, body { overscroll-behavior-y: none }` 无条件生效 + `.rail { position: sticky; height: 100vh }`。
  根滚动容器被判定为「不可滚动链」时，桌面端滚轮不再驱动页面滚动。
- 修法：把 `overscroll-behavior-y: none` 收进 `@media (hover: none) and (pointer: coarse)`，只在触屏生效；桌面端彻底不设。
- 另给 `.main` 加 `overflow-x: clip`（不是 `hidden`）——`clip` 不创建滚动容器，不会掐断根滚动。
- 守卫测试：`tests/scrollGuard.test.ts`（4 项）。

### 2. 抽签桶「没有图看着很 low」
- 原来未揭晓的签就是单个 `🎴` emoji，`.lot` 只有 `surface-2` 底色 + 边框。
- 改成**纯 CSS 绘制的签**：`.lot-body`（米色签身 `#efe3cd` + 左侧内阴影模拟圆柱感）
  + `::before` 顶部 9px 番茄红签头 + `.lot-face` 里竖排 `writing-mode: vertical-rl` 的「食」（17px 粗）+「签」（10px）。
- 新增 `.lot.dim`（未中奖的签在揭晓瞬间 `opacity .45 + scale .94` 退到后面），
