## 两处功能调整（用户提出）

1. **「换一个」要重新转转盘**：store 的 `againResult` 改为 `nextCandidate()`（只算下一道菜、不写 result），`Wheel.spin(targetId?)` 支持转到指定菜，抽签桶模式走 `shakeLots(targetId)` 重新洗牌。
2. **新增做菜难度**：`DishLevel = 1|2|3`，160 道菜逐道标注（脚本批量写入 `src/data/dishes.ts` 元组第 8 项），结果卡与补录列表显示徽章，筛选面板可按难度筛（`Filters.levels` + `toggleLevel`）。

## 环境坑（本机）

- Git Bash 会拦截 `npm`（wsl.exe 黑名单），npm 一律走 PowerShell。
- `npm install` 在本机 arborist 会报 `edgesOut` 错误，加 `--legacy-peer-deps --no-audit --no-fund` 可过。
- TS 6：`baseUrl` 已废弃，paths 改 `"@/*": ["./src/*"]`；tests 用 node API 需 `@types/node` 并加进 tsconfig types。
- Edit 工具偶发「返回成功但内容未落盘」，改完关键文件要用 grep 复核（本次踩到 4 次）。
