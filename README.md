# what-to-eat · 今天吃什么

解决「今天吃什么」的纯前端随机选菜工具：抽签决定菜品 → 一键记入三餐 → 月历回看 → 热量估算。
手机 / 平板 / 桌面响应式，无后端、无账号，数据全部保存在本地浏览器。

## 原型

打开 `prototype/index.html` 可在手机 390 / 平板 834 / 桌面 1440 之间切换预览；也可直接打开 `prototype/app.html`（响应式，随窗口宽度自适应）。

已确认范围：**v1 只给菜名 + 所需食材，不做菜谱做法**；**夜宵 v1 就做，设置里默认关闭**；仓库名 `what-to-eat`。

## 核心结论速览

- **关键决策**：菜系**不强制**前置选择，改为「默认全菜库随机（惊喜模式）+ 菜系作为可选筛选」的双入口。
- **差异化**：市面「随机决策类」与「饮食记录类」互不打通，本产品补的是「抽 → 记 → 看」这条闭环。
- **技术栈建议**：Vite + React 18 + TypeScript + zustand + localStorage，部署 GitHub Pages。
